# خطة العمل — صفحة تسجيل الدخول وإنشاء الحساب (NovaStore)

التاريخ: 11/08/2026
الحالة: بانتظار الموافقة (لم يتم تنفيذ أي شيء بعد)

---

## الهدف العام
تجهيز الواجهة الأمامية (Front-end) فقط لصفحة "تسجيل الدخول / إنشاء حساب" للمستخدم العادي،
جاهزة للربط بالواجهة الخلفية (Backend) في مرحلة لاحقة، دون المساس بأي كود موجود حاليًا.

---

## القواعد المتفق عليها (قبل التنفيذ)
1. لا تغيير ولا حذف لأي ملف أو تصميم أو كود موجود (index.html, main.js, settings.html, admin*, etc.).
2. العمل فقط على ملفات جديدة 100%.
3. الالتزام الكامل بمعايير إمكانية الوصول (A11y) — أولوية قصوى.
4. التصميم يتبع هوية المتجر الحالية: Tailwind CSS، خط Cairo، ألوان Indigo/Violet،
   الوضع الليلي، ترجمة AR/FR/EN، اتجاه RTL/LTR.
5. الحفظ محليًا عبر localStorage (محاكاة جاهزة لاحقًا للربط بالـ Backend).

---

## المهمة 1: أيقونة SVG احترافية لتسجيل الدخول / إنشاء الحساب
الهدف: أيقونة عصرية بنمط المتاجر العالمية (شخص داخل دائرة + سهم دخول)، بجودة Scalable.
- أيقونة `user-login` / `user-plus` بأسلوب Stroke-Based (نفس أسلوب أيقونات Lucide المستعملة في الموقع).
- تدعم ألوان الهوية (Indigo #4f46e5 / Violet #7c3aed) وتشتغل في الوضع الفاتح والليلي.
- أبعاد مرنة (w/h قابلة للتغيير) وعنوان aria-hidden="true".
- تُعرَض داخل صفحة الحساب (في الترويسة/العنوان) وتكون صالحة كأيقونة زر مستقبلًا في الهيدر.

## المهمة 2: صفحة تسجيل الدخول وإنشاء الحساب (ملف جديد: account.html)
بنية الصفحة الجديدة:
- ترويسة (Header) بنفس نمط index.html مع شعار NovaStore وزر "العودة للمتجر".
- بطاقة مركزية عصرية (Card) بعرض أقصى مناسب، ظل ناعم، زوايا دائرية (rounded-2xl/3xl).
- نظام تبديل (Tabs) بين وضعين: "تسجيل الدخول" و"إنشاء حساب" مع تمرير تركيز واضح بينهما.
- نموذج تسجيل الدخول: البريد الإلكتروني + كلمة السر + زر إظهار/إخفاء كلمة السر + زر "دخول".
- نموذج إنشاء حساب: الاسم الكامل + البريد الإلكتروني + كلمة السر + تأكيد كلمة السر + زر "إنشاء الحساب".
- زر "هل نسيت كلمة السر؟" (رابط وهمي جاهز للربط لاحقًا).
- رسائل خطأ تحت كل حقل + رسالة حالة عامة (role="alert" / aria-live) بأسلوب الموقع الحالي.

### سلوك وهمي (Front-end Only)
- التحقق من صحة المدخلات (Validation) محليًا: بريد صالح، كلمة سر 8 أحرف على الأقل، تطابق كلمتي السر.
- عند "إنشاء حساب": حفظ بيانات المستخدم في localStorage وتوجيه رسالة نجاح.
- عند "تسجيل الدخول": محاكاة التحقق من الحساب المخزن محليًا (وإن لم يوجد → رسالة خطأ واضحة).
- جميع الدوال منظمة في كائن واحد (مثل main.js) وجاهزة للاستبدال باستدعاء API لاحقًا.

### الترجمة (AR/FR/EN)
- قاموس ترجمات كامل لكل نصوص الصفحة (عنوان، حقول، أزرار، أخطاء، حالة).
- دعم اتجاه RTL للعربية و LTR للغات الأخرى (document.documentElement.dir).
- قراءة اللغة والثيم المحفوظين من localStorage مثل بقية الصفحات.

### إمكانية الوصول (A11y)
- رابط "تخطي إلى المحتوى" (Skip link) أعلى الصفحة.
- كل حقل مرتبط بـ <label> صريح + aria-describedby لرسالة الخطأ.
- aria-invalid عند الخطأ + aria-required للحقول الإلزامية.
- aria-pressed لأزرار التبديل (Tabs) + تمرير التركيز بين الأوضاع.
- زر إظهار/إخفاء كلمة السر بـ aria-label واضح وتحديث الحالة.
- :focus-visible بحدود Indigo واضحة (مطابقة للموقع).
- رسائل حالة تُقرأ تلقائيًا بقارئات الشاشة (aria-live="polite").

### الوضع الليلي (Dark Mode)
- كل الألوان لها بديل Dark (bg-gray-900 / gray-800 / gray-700) بنفس نسق الموقع.
- أيقونة الجلسة/الشخص تتبدل ألوانها تلقائيًا مع الوضع الليلي.
