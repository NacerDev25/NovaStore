1) الفهم الصحيح للمطلوب (مؤكد)
--------------------------------------------------------------
- إنشاء لوحة تحكم المسؤول (Admin Dashboard) كواجهة أمامية
  كاملة تسمح للمسؤول بنشر المنتجات.
- ربط اللوحة بصفحة تسجيل الدخول admin-login.html الموجودة.
- التحقق من البريد الإلكتروني وكلمة السر عبر JavaScript
  في هذه المرحلة، وعند الربط بالخلفية لاحقاً يصبح عبر
  قاعدة البيانات.
- لا يوجد أي تخزين محلي (localStorage) للبيانات في هذه
  المرحلة إطلاقاً.
- عدم تغيير أو حذف أي شيء من الموقع الحالي: ننفذ المطلوب
  فقط دون المساس بباقي الصفحات أو التصميم.

--------------------------------------------------------------
2) مبادئ ملزمة أثناء العمل
--------------------------------------------------------------
أ- عدم المساس بالموقع الحالي:
   - لا تعديل على index.html أو main.js أو sw.js أو أي ملف
     قائم ما عدا admin-login.html (التعديل المطلوب عليه).
   - لا حذف لأي ميزة حالية.

ب- تصميم مطابق لتصميم الموقع العام:
   - نفس الألوان (Indigo #4f46e5 / Violet #7c3aed).
   - نفس الخط (Cairo) ونفس أسلوب البطاقات والظلال.
   - دعم الوضع الليلي (dark mode) واللغات الثلاث
     (عربي RTL / فرنسي / إنجليزي LTR).
   - شعار NovaStore بنفس التنسيق.

ج- إمكانية الوصول (Accessibility):
   - بنية HTML دلالية + skip link + aria-label / aria-live
     / role + label مرتبطة بالحقول + رسائل خطأ مقروءة
     (role="alert") + تحكم بلوحة المفاتيح + تباين مناسب.

د- احترافية وتنظيم:
   - كود نظيف بتعليقات عربية مختصرة.
   - دوال مصممة للربط بالـ API لاحقاً (API-Ready) دون إعادة
     كتابة الواجهة.

--------------------------------------------------------------
3) قرارات صاحب المشروع (مؤكدة)
--------------------------------------------------------------
(1) طريقة التخزين: لا يوجد تخزين محلي في هذه المرحلة. ✅
(2) المحتوى المطلوب في اللوحة: نموذج نشر المنتجات فقط
    (بدون قسم "المنتجات المنشورة"). ✅
(3) معاينة حية لبطاقة المنتج أثناء الكتابة: ✅ موافق عليها
    (تم شرحها للمالك: بطاقة مصغّرة تتحدث فورياً أثناء كتابة
    النموذج كما ستظهر في المتجر).
(4) بعد نجاح تسجيل الدخول: توجيه مباشر إلى لوحة التحكم ✅
    (مع رسالة ترحيب صغيرة داخل اللوحة - التوصية المقدمة
    وتمت الموافقة عليها).

--------------------------------------------------------------
4) هيكل صفحة تسجيل الدخول (تعديل admin-login.html)
--------------------------------------------------------------
- الصفحة موجودة والنموذج جاهز (بريد إلكتروني + كلمة سر).
- سنفعّل التحقق عبر JS: مقارنة المدخلات ببيانات الاعتماد
  الافتراضية المكتوبة في القسم (7) بالأسفل.
- عند النجاح: توجيه مباشر إلى admin.html + إنشاء جلسة بسيطة
  (sessionStorage) تحمي الصفحة من الدخول المباشر.
- عند الفشل: رسالة خطأ واضحة (role="alert") وإتاحة إعادة
  المحاولة.
- دالة التحقق تُكتب بشكل يسهل استبدالها لاحقاً بنداء
  قاعدة البيانات.
- لا تعديل على التصميم الحالي للصفحة.

--------------------------------------------------------------
5) هيكل لوحة التحكم - ملف جديد: admin.html
--------------------------------------------------------------
أ- الترويسة (Header):
   - شعار NovaStore + زر العودة للمتجر + زر تسجيل الخروج.

ب- رسالة ترحيب صغيرة بعد الدخول.

ج- نموذج نشر المنتج (المحتوى الأساسي والوحيد المطلوب):
   - الحقول:
       * اسم/عنوان المنتج
       * وصف المنتج
       * السعر
       * التصنيف (عالم المرأة / عالم الرجل / قسم التقنية)
       * رابط صورة المنتج (URL)
       * رابط المنتج
       * اسم المتجر (أمازون / جوميا / علي إكسبريس / أخرى)
   - معاينة حية للصورة + معاينة حية لبطاقة المنتج كما
     ستظهر في المتجر (تتحدث فورياً أثناء الكتابة).
   - التحقق من الحقول عبر JS مع رسائل واضحة.
   - زر "نشر المنتج": يجمع البيانات في كائن منظم، ويعرض
     رسالة نجاح/جاهزية فقط (لا يخزن شيئاً)، والدالة مصممة
     لاحقاً لتُستبدل بإرسال fetch إلى الخادم.
   - زر إعادة تعيين النموذج (Reset) لنشر منتج آخر.

د- حماية الصفحة:
   - admin.html تتحقق من الجلسة (sessionStorage) عند فتحها،
     وإن لم يكن المسؤول مسجلاً: توجيه تلقائي إلى
     admin-login.html.

هـ- اللغة والثيم:
   - قراءة اللغة والثيم من إعدادات المستخدم وتطبيقها على
     اللوحة بنفس أسلوب بقية الصفحات.
